# UFO Sightings Power BI Analysis 👽

An interactive Power BI dashboard analyzing UFO sighting data by time, location, shape, and sighting duration.

## Project Overview

This project was built in Power BI to transform raw UFO sighting data into an interactive dashboard that allows users to explore patterns and trends across the dataset.

The project includes data cleaning and transformation with Power Query, DAX measures, interactive visualizations, filters, slicers, drill-down functionality, and customized visual interactions.

## Dashboard Features

- UFO sightings trend analysis by year
- Sightings by country and state
- Top 15 UFO shapes by number of sightings
- Country-to-state map drill-down
- Month filtering
- Date-range filtering
- Page-level filtering
- Visual-level Top N filtering
- Custom visual interactions
- Average sighting duration analysis
- Percentage of sightings lasting one hour or longer
- Interactive map tooltips

## Data Preparation

Power Query was used to clean and transform the dataset, including:

- Removing unnecessary columns
- Filtering invalid and blank values
- Creating date-related fields
- Cleaning and formatting text fields
- Creating calculated duration fields
- Preparing geographic fields for mapping

## DAX Measures

Custom measures were created for dashboard analysis, including:

- `# sightings`
- `avg sighting duration`
- `% hour-plus sightings`

## Visualizations

The final dashboard includes:

- Area chart
- Bar chart
- Interactive map
- Country/state slicer
- Month slicer
- Date slicer
- Custom dashboard image

## Filters

The dashboard includes:

- Sightings from 1983 and later
- Removal of blank and `unknown` shape categories
- Top 15 shapes ranked by number of sightings
